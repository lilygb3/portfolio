Portfolio 4 - CV

Goal

For this portfolio piece, I set out to code my CV in R as a way to strengthen my technical and professional skills. As I apply to Clinical Research Coordinator and Research Assistant positions, I wanted to create a document that not only presents my experience, but also demonstrates my programming ability and comfort working in R. After looking at several tutorials and templates, I chose to design my own layout so that I could fully understand the structure and styling decisions behind it (I also didn’t like any of the templates I found). A main goal of this project was to build a CV that is easily editable and adaptable over time. I still have so much to learn, and I hope to continue making this better as I progress. I hope to refine this into a cleaner, reusable template that could potentially be used by others as well.

Some references I used in this project: - R for Data Science - R Documentation: cat() - Rmd Cookbook - tribble() docs - CSS Flexible Box Layout - HTML Basics
